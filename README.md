# Капитал → 40 млн

Личный учёт денег: счета, имущество и долги, бумаги с решением «держать / продать», календарь купонов и дивидендов, бюджет по месяцам и прогноз по этапам 5 → 8 → 12 → 16 → 20 → 30 → 40 млн ₽.

Один файл `index.html`, без сборки и зависимостей (только шрифты Google Fonts).

## Где хранятся данные
Только в браузере (localStorage). В репозиторий цифры не попадают.
- **Экспорт** — сохраняет JSON-копию всех данных.
- **Импорт** — загружает JSON на другом устройстве или после очистки браузера.

## Как запустить
GitHub Pages: Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save.
Сайт: `https://pavelkostyukov.github.io/capital/`

Локально: просто откройте `index.html` в браузере.

## Как доработать
- Этапы цели — массив `LADDER` в начале скрипта.
- Типы счетов — `KIND_LABEL`, решения по бумагам — `VERDICT`.
- Прогноз — функция `project()`, ставка и пополнение задаются на вкладке «Обзор».
