# Капитал → 40 млн

Личный учёт денег по образцу renta.life: счета, бумаги с решением «держать / продать», календарь купонов и дивидендов, бюджет по месяцам и прогноз по этапам 5 → 8 → 12 → 16 → 20 → 30 → 40 млн ₽.

## Вкладки
- **Обзор и цель** — лестница этапов, прогноз, рычаги ускорения.
- **Пассив и дивиденды** — пассивный доход сейчас и сценарий роста дивидендов акций: 3 / 5 / 10 лет, пополнения с индексацией, реинвест или трата выплат, срок достижения цели по пассиву.
- **Планы** — продажи активов, поступления (премия, наследство) и крупные траты: налог с учётом убытков года и эффект на сроки этапов.
- **Счета**, **Бумаги**, **Выплаты**, **Бюджет** — учёт.
- **Штанга** — целевая структура портфеля против факта: сколько докупить или сократить в каждом блоке.
- **Налоги и задачи** — налоговая чистка убытками, трекер оборота для статуса квала, список задач.

Один файл `index.html`, без сборки и зависимостей (только шрифты Google Fonts).

## Где хранятся данные
Только в браузере (localStorage). В репозиторий цифры не попадают: в `index.html` лежит только пример (`SAMPLE_DATA`), он показывается, пока вы не импортировали свой файл.
**Не коммитьте** файлы `kapital-*.json` — они в `.gitignore`, репозиторий публичный.
- **Экспорт** — сохраняет JSON-копию всех данных.
- **Импорт** — загружает JSON на другом устройстве или после очистки браузера.

## Как запустить
GitHub Pages: Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save.
Сайт: `https://pavelkostyukov.github.io/capital/`

Локально: просто откройте `index.html` в браузере.

## Как доработать
- Этапы цели — массив `LADDER` в начале скрипта.
- Типы счетов — `KIND_LABEL`, решения по бумагам — `VERDICT`.
- Прогноз — функция `project()`, ставка и пополнение задаются на вкладке «Обзор».
- Сценарий роста дивидендов — `incomeSim()`, планы и налог — `plans()` / `planTaxes()`.
- Блоки «штанги» — `BLOCKS` и `guessBlock()`, целевые доли — `DEFAULT_SETTINGS.target`.
