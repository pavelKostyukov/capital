# Капитал → 40 млн

Личный учёт денег по образцу renta.life: счета, бумаги с решением «держать / продать», календарь купонов и дивидендов, бюджет по месяцам и прогноз по этапам 5 → 8 → 12 → 16 → 20 → 30 → 40 млн ₽.

## Вкладки
- **Обзор** — путь к 40 млн: этапы, прогноз, пополнение в месяц и рычаги ускорения; карточка «Финансовая свобода»: какую часть расходов из «Расходов» уже покрывает портфель по правилу 4%, сколько капитала ещё нужно и когда он наберётся (расходы — по бюджету, по факту за 12 месяцев, только повседневные или своя сумма; ставку изъятия можно поменять).
- **Портфель** — из чего состоит портфель и где лежат деньги, результат за всё время, «снежный ком».
- **Анализ** — облигации, акции и фонды по отдельности: доходность, дивиденды, отрасли.
- **Советы** — куда вложить пополнение и что делать с каждой бумагой; раздел «Штанга»: целевая структура против факта.
- **Пассив** — пассивный доход: факт за 12 месяцев и прогноз; «Выплаты по месяцам»: что пришло за 12 месяцев и что уже известно на 12 вперёд (бледные столбики — ожидаются), нажатие на месяц показывает список выплат, есть вид по годам; «Когда пассив дойдёт до цели»: график по месяцам с подсказками при наведении или нажатии, точками по годам и отметкой месяца, когда пассив дойдёт до цели, карточки и таблица на 3 / 5 / 10 лет; раздел «Выплаты»: календарь купонов и дивидендов по годам.
- **Расходы** — траты из Monefy, бюджет, сколько остаётся на инвестиции; раздел «Учёт по месяцам»: доход и расход вручную.
- **Планы** — калькулятор капитала: старт, срок, доходность, пополнения и их частота, реинвест, налог по итогам года, инфляция и индексация, график капитала против вложенного и сроки этапов до 40 млн (кнопка «Калькулятор» в шапке ведёт сюда); режим «Что посчитать»: итоговую сумму, срок, пополнение, стартовый капитал или ставку, которые нужны для суммы из поля «Хочу накопить», и кнопка «Сбросить»; продажи активов, поступления и крупные траты с налогом; раздел «Налоги и задачи»: налоговая чистка, оборот для квала, задачи.
- **Счета** — ручной ввод: счета, имущество и долги; раздел «Бумаги»: бумаги во всех счетах и решение «держать / продать».
- **Подключения** — Т-Инвестиции по токену «только для чтения»: счета, бумаги, купоны и дивиденды подтягиваются сами: портфель раз в минуту, выплаты раз в 10 минут, пока сайт открыт. Токен хранится только в браузере (localStorage), в экспорт и репозиторий не попадает. Если браузер не пускает запросы к API напрямую, во вкладке есть код прокси для Cloudflare Workers.

Один файл `index.html`, без сборки и зависимостей (только шрифты Google Fonts). Тема по умолчанию светлая, кнопка в шапке переключает на тёмную; выбор запоминается в этом браузере.

## Где хранятся данные
Только в браузере (localStorage). В репозиторий цифры не попадают: в `index.html` лежит только пример (`SAMPLE_DATA`), он показывается, пока вы не импортировали свой файл.
**Не коммитьте** файлы `kapital-*.json` — они в `.gitignore`, репозиторий публичный.
- **Экспорт** — сохраняет JSON-копию всех данных.
- **Импорт** — загружает JSON на другом устройстве или после очистки браузера.

## Как запустить
GitHub Pages: Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save.
Сайт: `https://pavelkostyukov.github.io/capital/`

Локально: просто откройте `index.html` в браузере.

## Как доработать
- Этапы цели — массив `LADDER` в начале скрипта.
- Типы счетов — `KIND_LABEL`, решения по бумагам — `VERDICT`.
- Прогноз — функция `project()`, ставка и пополнение задаются на вкладке «Обзор».
- Калькулятор капитала — `calcRun()` (расчёт по месяцам) и `calcHTML()` / `calcOut()`.
- Обратный расчёт калькулятора («Что посчитать») — `calcSolve()`.
- Сценарий роста дивидендов — `incomeSim()` и график `passChart()`, планы и налог — `plans()` / `planTaxes()`.
- Выплаты по месяцам — `payMonths()` / `payBars()`, карточка «Финансовая свобода» — `fiState()` / `fiHTML()`.
- Подсказки на графиках при наведении и нажатии — `tipChart()` / `bindCharts()`.
- Блоки «штанги» — `BLOCKS` и `guessBlock()`, целевые доли — `DEFAULT_SETTINGS.target`.
